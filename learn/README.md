# 學國字 ㄅㄆㄇ ・ 長輩友善的中文學習小工具

一個單一檔案的網頁小工具，設計給不熟悉繁體字與注音的長輩使用。
手機打開瀏覽器就能用，不用安裝、不用註冊、不用網路帳號。

## 功能

| 功能 | 說明 |
| --- | --- |
| 看圖學字 | 一張一張圖卡，圖片 ＋ 繁體字 ＋ 注音，按一下就用國語唸出來 |
| 聽聲音選字 | 唸出一個詞，從三個選項裡選出正確的字 |
| 看圖選字 | 看圖片，選出對應的國字 |
| ㄅㄆㄇ 注音練習 | 37 個注音符號表（附例字發音）、四聲與輕聲、注音配對測驗 |
| 寫字練習 | 米字格描紅，用手指直接在螢幕上寫，提示深淺可調 |
| 我的紀錄 | 今天練習題數、連續天數、學會的字詞、各主題進度 |
| 設定 | 字體大小三段、說話速度三段、注音顯示開關、語音選擇 |

## 長輩友善的設計

- 內文最小 20px，可再放大到 1.3 倍；主要字卡 76px 以上
- 所有可按的地方最小高度 72px，選項卡片 110px
- 每題最多三個選項，答完會立刻用顏色 ＋ 聲音 ＋ 語音回饋
- 不使用滑動手勢、不使用純圖示按鈕，返回鍵固定在左上角
- 答錯不扣分、不催促，會直接把正確答案唸一次
- 第一次點擊時不會改動版面（避免手指按下後畫面位移導致按空）

## 內容

- 98 個常用字詞，分成 9 個主題：家人、身體、食物、日常用品、動作、地方、天氣自然、數字、時間
- 注音採台灣教育部標準，輕聲以「˙」標在音節前（例：爸爸 ㄅㄚˋ ˙ㄅㄚ）
- 圖卡使用系統內建的表情符號，不需要下載任何圖片

## 語音

使用瀏覽器內建的語音合成（Web Speech API），優先選擇 `zh-TW` 台灣國語語音。

- **iPhone / iPad**：Safari 內建中文語音，可直接使用
- **Android**：若沒聲音，到「設定 → 系統 → 語言與輸入 → 文字轉語音輸出」下載「中文（台灣）」語音
- 找不到台灣語音時會自動改用其他中文語音，並在「設定」頁面顯示提醒

## 使用方式

用手機瀏覽器打開 `index.html` 即可（建議 Chrome 或 Safari）。
所有設定與練習紀錄都存在手機瀏覽器裡，不會上傳到任何地方。

## 給家人的建議

1. 先陪媽媽把「設定」調好：字體選「最大」、說話速度選「很慢」
2. 從「看圖學字」開始，一次一個主題就好，不用貪多
3. 熟了再玩「聽聲音選字」，最後才練「寫字練習」
4. 每天 10 分鐘比一次練半小時有效，「我的紀錄」可以看連續天數
