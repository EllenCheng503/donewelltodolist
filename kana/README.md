# 仮名けいこ · 從零學五十音

一個單檔、離線可用的日文五十音學習工具，為**完全零基礎**設計。用瀏覽器打開 `kana/index.html` 就能用，手機加到主畫面後跟 App 一樣。

## 核心流程：先教會，再測驗

不是一上來就丟選擇題。每一課先把 5 個字**教一遍**，學完這 5 個字才測這 5 個字。

**學習卡**（每個字一張）包含：

- 大大的假名，旁邊是同樣大的羅馬拼音
- **漢字來源**——這是重點，見下一節
- 字形聯想（一句話）
- 筆畫數與筆順通則
- 容易搞混的字提醒（あ 會提醒你別跟 お、ぬ、め 混）
- 當場就能描的十字格，淡色範本照著描
- 發音按鈕（裝置有日文語音時才出現）

**課後測驗**只考剛學的那 5 個字，每個字考三種：看假名選讀音、看讀音選假名、看讀音默寫。選擇題的選項也**只從你學過的字裡出**——不會冒出還沒教過的字讓你亂猜。

答不出來可以按「想不起來，給我提示」，會顯示字源聯想而不直接給答案；用過提示的題目會再出現一次。

## 為什麼強調漢字來源

平假名是漢字的**草書**簡化來的，片假名是取漢字的**偏旁**：

| | |
|---|---|
| あ ← 安 | ア ← 阿（左半） |
| か ← 加（左半「力」）| カ ← 加（就是「力」）|
| ろ ← 呂 | ロ ← 呂（上半，就是「口」）|
| ん ← 无 | ニ ← 二（就是「二」，ni＝two）|
| | ハ ← 八（就是「八」）|
| | ミ ← 三（就是「三」，剛好三筆）|

你是中文母語者，已經認得這些漢字了——這是學五十音最大的優勢，比死背有效得多。92 個假名的字源全部寫進去了。

## 課程結構

共 40 課，每課 3–9 個字：

1. 平假名清音（11 課，46 字）
2. 片假名清音（11 課，46 字）
3. 平假名濁音・半濁音（5 課）
4. 片假名濁音・半濁音（5 課）
5. 平假名拗音（4 課）
6. 片假名拗音（4 課）

課程不上鎖，想跳著上也可以，首頁的「繼續學習」會自動指向下一課。濁音那一章開頭會說明「゛」和「゜」的規則——字形完全不用重學；拗音那章會說明小的ゃゅょ怎麼拼。

## 間隔複習

每個學過的假名各自記錄熟練度（0–6 級）。答對升一級、答錯降兩級，複習間隔隨等級拉長：1 分鐘 → 10 分鐘 → 1 天 → 2 天 → 5 天 → 12 天 → 30 天。有字到期時，首頁會出現「今日複習」。

首頁下方的五十音圖是完整字表，每格都有假名和羅馬拼音，隨時可以當字卡查。顏色越深＝記得越牢，右上角紅點＝今天該複習。

## 干擾選項是刻意挑的

選擇題的錯誤選項不是隨機抽的，優先從「已知會互相搞混的字組」裡挑——出 `ツ` 時選項會有 `シ`、`ソ`、`ン`，出 `テ` 就配 `チ`、`ナ`。答錯時下方也會列出容易混淆的同伴。分不清這幾組是最大的卡點，隨機出題練不到。

`シ / ツ` 和 `ソ / ン` 的分辨方式寫在字源說明裡：**點的位置和尾巴的方向**（シ・ツ 尾巴由下往上挑，ソ・ン 由上往下撇）。

## 進階：自由練習

已經有基礎、想直接大量刷題時，首頁最下方展開「自由練習」：自己選範圍（六個牌組）和題型（認字／打字／反查／手寫），不跟著課程走。打字模式會接受訓令式拼法（`si`、`tu`、`sya`⋯）。

## 資料範圍

清音 46 + 濁音・半濁音 25 + 拗音 33，平假名與片假名各一套，共 208 個項目。`ぢ` 和 `づ` 標示為 `ji (di)` / `zu (du)` 以便和 `じ`、`ず` 區分，打字時兩種拼法都接受。

## 字體選擇

辨識題用**明朝體**顯示假名，因為那是書本和考卷上會看到的樣子；手寫的描摹範本改用**黑體**，字形比較接近手寫的筆畫形狀。這是刻意的區分，不是疏漏。

## 資料儲存

全部進度存在瀏覽器的 localStorage，不會上傳、不需要帳號。換裝置或清瀏覽器資料就會歸零。首頁最下方可以手動清除紀錄。

## 已知限制

沒有內建逐筆的筆順動畫——那需要每個假名的向量筆畫資料。目前用的是「範本描摹 + 筆畫數即時對照」，配合筆順通則（由上到下、由左到右）在實務上夠用：如果你寫完的筆畫數跟標示的對不上，通常就是筆順記錯了。要確認某個字的精確筆順，還是得查筆順表。

發音需要裝置本身有日文語音（iOS、Android 大多內建）；沒有的話發音按鈕不會出現，其他功能不受影響。
